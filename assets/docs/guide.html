User Guide

Getting started with the tools on pyaek.com.

AI Chat

Visit /apps/ai/ to use the AI chat. Add your own API keys in Settings, choose a connection and agent, then start chatting. Works offline after first load.

ETL Studio

Visit /apps/etl/ to clean and transform data in your browser. Load CSV, Parquet, or JSON files, run SQL transformations, and export results. All processing stays on your device.
